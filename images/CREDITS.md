# 지도 이미지 출처·라이선스

- **파일**: `jianghu-antique-map.webp` (3000 × 2000 px)
- **성격**: 무림여지도를 위해 제작한 **창작 수묵 고지도**입니다. 실제 고지도 스캔본이나 퍼블릭 도메인 사본이 아닙니다.
- **제작**: 2026-11-24, 프로젝트용으로 이미지 생성 도구로 만든 원본(`downloads/jianghu-antique-map-raw.png`)을 웹 배포용 WebP로 변환했습니다.
- **권리**: 프로젝트 소유자가 직접 제작·보유한 이미지이며, 외부 지도 타일을 쓰지 않습니다.
- **주의**: 지도 위 지형·해안선은 상징적으로 그린 것이며 측량 자료가 아닙니다. 문파 위치는 `src/data/*.json`의 `map_position`(픽셀, 좌상단 원점)으로만 지정하고, 실제 위치는 `geo`에 참고용으로만 둡니다(01_architecture.md 3절).
